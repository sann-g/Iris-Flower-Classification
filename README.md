# Iris Flower Classification using Machine Learning

This project uses Machine Learning to classify iris flowers into different species based on their measurements.

## Dataset
The dataset contains:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

Species:
- Iris-setosa
- Iris-versicolor
- Iris-virginica

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Algorithm
- Logistic Regression

## Features
- Data visualization
- Pairplot graph
- Heatmap
- Model training
- Prediction system
- Accuracy evaluation
- Confusion matrix

## Accuracy
The model achieved nearly 100% accuracy.

## How to Run

Install required libraries:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn
```

Run the project:

```bash
python iris_project.py
```
